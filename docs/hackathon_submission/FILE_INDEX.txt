QUICK START GUIDE
=======================================================================

FOR EVALUATORS:

1. Read README.txt first (complete overview)
2. Check DATASET_STATISTICS.xlsx (data overview)
3. Review HYPERPARAMETERS.txt (all training parameters)
4. Review VALIDATION_PERFORMANCE.txt (results)
5. Inspect TRAINING_CODE.py (training implementation)
6. Inspect MODEL_ARCHITECTURE.py (model definition)

FOR REPRODUCTION:

1. Ensure dataset is at: ../train/train/blur and ../train/train/sharp
2. Run: python TRAINING_CODE.py
3. Best model will be saved to: ../checkpoints/best_model_improved.pkl
4. Expected result: 29.86 dB validation PSNR at epoch 29

FOR TESTING:

1. Run: python ../test_improved_model.py
2. Visual comparison will be generated
3. PSNR metrics will be displayed
