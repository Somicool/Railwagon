================================================================================
TRAINING DATASET SUMMARY
================================================================================

The model submitted for Round 1 was trained EXCLUSIVELY on:
   - Railway Wagon Dataset (1066 pairs)
   - train/train/blur/ and train/train/sharp/
   - Motion-blurred railway wagon images
   - 91.7% blur severity

Why only railway wagon data?
   - Domain-specific performance for railway inspection
   - Consistent blur type (motion blur from moving wagons)
   - Real-world railway wagon characteristics
   - Better performance on target application

GoPro and LOL datasets exist in the workspace for reference but were
deliberately NOT used to maintain domain specificity.
